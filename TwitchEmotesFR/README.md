# Twitch Emotes FR

French streamer edition of **Twitch Emotes WoW Forever** by **TheMizeGuy**:
https://github.com/TheMizeGuy/WowForeverTwitchEmotes

This is an **unofficial, modified version**. It is not made or endorsed by TheMizeGuy or by the
streamers it includes. Source of this version: https://github.com/Xanjar/WowForeverTwitchEmotes

Changes from the original: French streamer channels (Kameto, Locklear, Mynthos, Gotaga, Doigby,
ZeratoR, Etoiles, Botkz, Hiro) in place of the original's channels, every channel enabled by
default, and renamed folder, saved variable (TwitchEmotesFRDB) and slash commands (/tefr, /twitchfr)
so it can be installed next to the original.

The addon code is under the LICENSE file in this folder. Emote artwork belongs to its own rights
holders; see ASSET-NOTICES.md.
